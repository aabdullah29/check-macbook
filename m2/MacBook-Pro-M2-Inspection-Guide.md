# MacBook Pro 13-inch M2 (2022) — Complete Used-Mac Inspection Guide

**Target:** MacBook Pro 13-inch M2 (2022), advertised as **24 GB unified memory / 512 GB SSD**.

**Recommended inspection time:** 30–45 minutes.

> The goal is to find ownership/security problems, hardware faults, damage from the corner impact, battery problems, and functional issues **before payment**.

---

## 1. Confirm the Basic Configuration

Open:

** Apple menu → About This Mac**

Check:

- [ ] Model: MacBook Pro
- [ ] Chip: Apple M2
- [ ] Memory: 24 GB

Then open:

**Option +  → System Information**

Check:

- [ ] Hardware Overview
- [ ] Memory
- [ ] Power
- [ ] Storage
- [ ] Displays
- [ ] USB
- [ ] Thunderbolt/USB4
- [ ] Audio
- [ ] Camera
- [ ] Wi-Fi/Bluetooth

The 2022 13-inch M2 MacBook Pro was officially configurable with **24 GB unified memory** and **512 GB SSD**, so this configuration is valid.

Apple specifications:
https://support.apple.com/en-ie/111869

# 2. Serial Number and Model Verification

Get the serial from:

** → About This Mac**

or:

**Option +  → System Information → Hardware**

You can also run:

```bash
ioreg -l | awk -F'"' '/IOPlatformSerialNumber/ {print $4; exit}'
```

Record it:

**Serial: ______________________________**

Compare:

- [ ] macOS serial
- [ ] Physical serial on the Mac
- [ ] Box/invoice serial, if available

Check the serial with Apple's official coverage page:

https://checkcoverage.apple.com/

Verify that it corresponds to the expected Mac.

> A matching serial is useful, but it does not prove that every internal part is original or that the Mac has never been repaired.

# 3. Physical Inspection

Use your phone flashlight.

## Bottom case

- [ ] Dent
- [ ] Cracks
- [ ] Bent aluminum
- [ ] Open/separated seams
- [ ] Missing/damaged screws
- [ ] Loose bottom cover
- [ ] Signs of previous opening
- [ ] Liquid/corrosion signs

## Top lid

- [ ] Dent/scratch
- [ ] Cracked display glass
- [ ] Damaged bezel
- [ ] Damaged corners
- [ ] Hinge damage
- [ ] Unusual gaps

## Special attention to the damaged right corner

Because this Mac has impact damage around the right trackpad/palm-rest corner and corresponding lid damage, inspect:

- [ ] Right palm-rest area
- [ ] Right trackpad edge
- [ ] Right display corner
- [ ] Right hinge
- [ ] Lid/base alignment
- [ ] Any new gap around the impact

### Do not physically stress the Mac

Do **not**:

- [ ] Press hard on the dent
- [ ] Bend the display
- [ ] Twist the chassis
- [ ] Force the hinge
- [ ] Deliberately flex the palm rest

You are looking for existing symptoms, not trying to create a stress test.

Check:

- [ ] Smooth opening
- [ ] Smooth closing
- [ ] No grinding
- [ ] No clicking
- [ ] No unusual stiffness
- [ ] No excessive looseness
- [ ] Display remains aligned
- [ ] Left/right edges sit normally when closed
- [ ] No unusual gap near the damaged corner

# 5. Display Test

The 2022 13-inch M2 MacBook Pro has a **13.3-inch 2560×1600 Retina IPS display** with 500-nit brightness, P3 color and True Tone.

Apple specifications:
https://support.apple.com/en-ie/111869

Dead-pixel check:
https://displaytech.org/en/tests/dead.pixel.htm

## White screen

Display a completely white image.

Check:

- [ ] No dark spots
- [ ] No unusual yellow/colored patches
- [ ] No lines
- [ ] No flickering
- [ ] No obvious dead pixels

Pay special attention to the damaged corner.

## Black screen

Display a completely black image in a reasonably dark environment.

Check:

- [ ] No abnormal bright spots
- [ ] No bright lines
- [ ] No damaged area around the impact
- [ ] No flickering

Do not confuse normal IPS characteristics with damage.

## Red / Green / Blue

Display full-screen:

- [ ] Red
- [ ] Green
- [ ] Blue

Look for:

- [ ] Dead pixels
- [ ] Stuck pixels
- [ ] Color anomalies

## Brightness

Move brightness from low to maximum.

Check:

- [ ] Smooth brightness changes
- [ ] No flicker
- [ ] No sudden blackout
- [ ] No abnormal behavior around the damaged corner

## True Tone

Open:

**System Settings → Displays**

- [ ] True Tone is available
- [ ] True Tone works normally

# 14. Charging

Test with the seller's charger first.

- [ ] Charging starts
- [ ] Battery percentage increases
- [ ] Charging remains stable
- [ ] Both USB-C ports can charge

The original Apple configuration uses a **67W USB-C Power Adapter**.

# 15. Battery

Open:

**Option +  → System Information → Hardware → Power**

Record:

- **Cycle Count:** __________________
- **Condition:** ____________________
- **Maximum Capacity:** _____________

Apple's official battery-cycle instructions:
https://support.apple.com/en-au/102888

The listing information previously indicated approximately **67 cycles / 100% maximum capacity**. Treat those as claims to verify, not as expected values.

Good signs:

- [ ] Condition: Normal
- [ ] No service warning
- [ ] No unexpected shutdowns
- [ ] No abnormal percentage drops
- [ ] No swelling

> 100% maximum capacity does not by itself prove that the battery is original.

If there are signs of battery swelling, stop pressing/testing the affected area.

---

# 16. Storage

Open:

**System Settings → General → Storage**

Then Terminal:

```bash
diskutil list
```

and:

```bash
diskutil info /
```

Check:

- [ ] Internal storage detected
- [ ] Expected capacity
- [ ] APFS
- [ ] Startup volume normal

Then run:

```bash
diskutil verifyVolume /
```

Check that verification completes without an error.

> This verifies the filesystem/volume. It is not a complete physical NAND/SSD health certification.

---

# 17. Memory

Run:

```bash
system_profiler SPHardwareDataType
```

Confirm:

```text
Chip: Apple M2
Memory: 24 GB
```

Apple-silicon Macs use unified memory, so there are no removable RAM modules.

Check:

- [ ] 24 GB reported
- [ ] Apple Diagnostics passes
- [ ] No crashes
- [ ] No repeated kernel panics

---

# 18. MDM / Device Management

Check whether the Mac is managed by an organization.

Terminal:

```bash
profiles status -type enrollment
```

Then:

```bash
sudo profiles show -type enrollment
```

Look for:

- [ ] Device enrollment
- [ ] Automated Device Enrollment
- [ ] Organization
- [ ] MDM server
- [ ] Management profile

Also inspect:

**System Settings → General → Device Management**

or the equivalent management/profile section available on that macOS version.

> Do not use the absence of a Profiles menu alone as proof that the Mac is clean.

The strongest test comes later: **erase → Setup Assistant → Wi-Fi → check for Remote Management/organization enrollment.**

---

# 19. Crash / Kernel Panic Check

Run:

```bash
log show --last 1d --predicate 'eventMessage CONTAINS[c] "panic"' --style compact
```

Look for repeated recent kernel-panic records.

- [ ] No recent repeated panics
- [ ] No unexplained repeated crashes

One old record is not automatically a reason to reject the Mac; repeated recent panics are much more concerning.

Do several things:

- [ ] Browse websites
- [ ] Play high-resolution video
- [ ] Open several applications
- [ ] Copy a large file if available
- [ ] Use keyboard/trackpad continuously
- [ ] Play audio

Watch for:

- [ ] Freeze
- [ ] Restart
- [ ] Shutdown
- [ ] Display artifact
- [ ] Charging interruption
- [ ] USB disconnect
- [ ] Severe abnormal heat
- [ ] Kernel panic

The Mac can become warm and the fan can run under load. That alone is not a failure.

# 22. Apple Diagnostics

Run this near the end of the hardware inspection.

### Start Apple Diagnostics on M2

1. Shut down the Mac.
2. Press and hold the **power button**.
3. Keep holding until **Loading startup options** appears.
4. When Startup Options appears, release the power button.
5. Press and hold:

```text
Command (⌘) + D
```

6. Follow the onscreen instructions.
7. Connect to Wi-Fi if requested.
8. Let the test finish.
9. Record the exact result/code.

Official Apple instructions:

https://support.apple.com/en-us/102550

Result/code:

**________________________________**

> A clean Apple Diagnostics result is a strong positive sign, but it does not prove that the Mac has no cosmetic/structural damage, no previous repair, no intermittent fault, or that every internal part is original.

If you receive an unexpected code, record the exact code and investigate it before paying. Do not rely on an unverified code list.

# 23. Final Ownership and Activation Test

**Do this only after the hardware checks pass.**

This is intentionally near the end because it can erase the seller's data and change the state of the Mac.

Ask the seller:

> "Everything looks good so far. Before I pay, I need to verify that the Mac can be cleanly erased and activated by the next owner."

The seller should remain present.

## 23.1 Seller removes Apple Account / Find My

The seller should remove their Apple Account/Find My association as part of the handover.

On the Mac:

**System Settings → [seller's name] → iCloud → Find My Mac**

The seller can turn off Find My and authenticate with their Apple Account.

Apple states that turning off Find My disables Activation Lock on the Mac:

https://support.apple.com/en-lamr/102541

## 23.2 Erase the Mac

Use:

** → System Settings → General → Transfer or Reset → Erase All Content and Settings**

Follow the onscreen instructions.

## 23.3 Setup Assistant

After the erase:

1. Start Setup Assistant.
2. Connect to Wi-Fi.
3. Continue through setup.
4. Watch carefully for:

- [ ] Previous-owner Apple Account / Activation Lock request
- [ ] Remote Management
- [ ] Organization name
- [ ] Company/school enrollment

### Stop the purchase if:

- [ ] Previous owner's Apple Account is required
- [ ] Activation Lock remains
- [ ] Remote Management appears unexpectedly
- [ ] An organization claims the Mac
- [ ] Seller says the problem can be fixed later

Apple documents that Activation Lock is enforced during activation and that Apple-silicon Macs can also be subject to organization/device-management controls.

https://support.apple.com/en-lamr/102541
